# ABOUT｜页面执行卡

## 页面定位

ABOUT 采用统一的“白墙画廊 / 艺术空间”视觉语言，同时保留现有纵向阅读结构、内容顺序和已经确认的交互内容。

正式背景资产：
- A01 白墙纹理：平面墙面、文字区、滚动菜单区、信息密集区、收尾区
- A02 空白画廊空间：首屏、中段空间区、四列兴趣陈列区

## 1｜首屏：时间线成为墙上的动态作品

现有时间线动画继续作为首屏核心内容。
它以“画廊墙面上的一幅动态作品”呈现。

画面分层：
1. A02 / 同材质墙面作为空间背景。
2. 新建画框前景资产，带透明 alpha 与透明画芯窗口。
3. 时间线动画作为实时网页内容置入画芯窗口。
4. 画框、墙面、动画保持统一透视、尺度和光线关系。

Codex 需要制作：
- `ABOUT_HERO_FRAME_OVERLAY.webp`：透明背景，画芯区域透明，边缘干净，适合直接叠加。
- `ABOUT_HERO_FRAME_MASK.svg`：用于准确裁切 / 定位时间线动画。
- `ABOUT_HERO_COMPOSITION_TEST.png`：用于自查比例与透视，作为审核证据。

时间线内容、播放逻辑和原有动画语义保持基线。

## 2｜滚动菜单 / 信息密集区

使用 A01 白墙纹理作为连续背景。
现有滚动菜单与文本组件直接位于墙面上。
页面保持正常纵向滚动阅读。

## 3｜墙面标语

页面已有品牌标语采用“印刷在墙面”的质感：
- 使用当前字体体系或页面已确认标题字体。
- 深灰 / 暖灰文字融入白墙。
- 通过透明度、blend、字重和排版形成墙面印刷感。
- 保持实时文本属性，支持响应式、复制和可访问性。

品牌文字：
`将经验沉淀成资产`
`拥有的任何经验都将回报价值`

## 4｜中段内容

信息阅读密集区优先使用 A01。
需要空间层次的内容区使用 A02。
所有区块保持同一白墙色温、颗粒尺度与光线语言。

## 5｜未来兴趣 / 关注方向四列

现有四列内容以“四幅作品并列陈列”的节奏组织。
使用 A02 作为空间基底。
四列继续作为真实网页组件，支持现有响应式与内容更新。
