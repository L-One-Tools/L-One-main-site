# WORK｜页面执行卡

## 页面定位

WORK 保持“四个项目文字 + 四个项目视觉”的核心结构，并强化版心、色彩联动、标题字体、项目内部目录与本地视频详情体验。

## 1｜列表页版心

- 左侧四个项目大标题与右侧项目主图整体向页面中轴聚拢。
- 页面两侧获得更宽的留白。
- 大标题与右侧主图之间形成更紧凑的信息连接区。
- 1440×900 视口中，四个项目标题、当前主视觉和核心导航形成完整构图。

## 2｜项目内部小标题目录

大标题与右侧主图之间的留白区域承担“项目内容目录”。

每个项目读取其真实内容标题：
- 1 条内容显示 1 条
- 4 条内容显示 4 条
- 10 条内容完整显示 10 条

目录采用较小字号与紧凑行距，形成项目内容索引。
当前项目切换时，该目录同步更新。
点击目录项进入对应详情视频或切换当前视频。

## 3｜背景主题

WORK 使用两套页面主题：
- 米白主题
- 深灰主题

每个项目根据当前首图的视觉明度与主体关系指定 `theme: ivory | charcoal`。
项目切换时，页面背景、文字、底部 About 返回按钮同步切换主题。

主题关系：
- charcoal：普通文字使用柔和浅灰 / 白灰；选中标题使用当前主题最高对比、最高强调的亮白。
- ivory：普通文字使用中性灰；选中标题使用当前主题最高对比、最高强调的深石墨色。
- About 返回按钮使用与当前主题一致的高可读对比色。

颜色最终记录到 WORK COLOR_REGISTER，并通过真实截图完成确认。

## 4｜中文标题字体与选中态

四个中文项目标题使用更圆润、较宽字面、厚实且具展示感的中文字体。
字体需要适配现有“选中标题纵向拉高、相邻标题同步压缩”的动态效果。

现有标题拉伸、回弹、相邻文字压缩和整体行距关系保持基线节奏。

选中态从固定强调色升级为主题强调色：
- 深灰主题：选中标题呈现最亮白。
- 米白主题：选中标题呈现最高对比的深石墨色。
普通标题降低一个视觉层级。

## 5｜四个项目详情页：本地视频重建

所有作品详情统一读取用户提供的本地作品目录。
Codex 开工时接收：
`{{WORK_LOCAL_ASSET_DIR}}`

扫描目录后生成 `WORK_LOCAL_ASSET_MAP.json` 与 `WORK_LOCAL_ASSET_MAP.md`。

每个视频记录：
- project_id
- project_title
- video_id
- video_title
- source_path
- duration
- width
- height
- aspect_ratio
- file_size
- poster_path
- cloud_video_url
- cloud_poster_url
- display_order
- short_description（优先读取当前网站已确认项目文案 / 用户映射信息）

使用 ffprobe 读取时长、尺寸、画幅、编码和码率。

## 6｜网页播放版与腾讯云

腾讯云轻量服务器 40GB 云硬盘作为网站视频播放资源空间。

流程：
1. 检查当前服务器剩余容量与部署目录。
2. 为每支源视频生成网页播放版。
3. 统一 MP4 / H.264 / yuv420p / AAC。
4. 写入 `faststart`，让 MP4 索引位于文件头部。
5. 为移动端准备更轻的播放版本时，以实际存储预算与移动端测试结果决定 720p 版本。
6. 云端媒体目录保持至少 20% 可用空间。
7. 配置正确 MIME、Cache-Control、Content-Length 与 byte range。
8. 用 curl / Network 面板确认 Range 请求返回 206。
9. 上传后写入云端 URL，并更新作品数据文件。

## 7｜预加载顺序

进入 WORK 列表页：
- 加载全部项目 poster、标题、时长与基础 metadata。
- 当前选中项目第一支视频进入优先缓冲。
- 页面进入空闲阶段后预热相邻项目第一支视频。

进入详情页：
- 当前视频获得最高加载优先级。
- 下一支视频进入预备缓冲。
- 切换视频时延续当前播放器音量状态。

## 8｜详情页布局

桌面端继续采用左右关系：
- 左侧：项目大标题与项目简介
- 中间窄列：视频标题列表 + 当前视频 metadata
- 右侧：视频主体

metadata 建议显示：
`视频标题 / 时长 / 画幅`，并使用短行小字呈现。

视频主体按源画幅完整显示。
横版视频优先使用 16:9 舞台；其他画幅使用 contain 逻辑保持完整画面。

## 9｜极简播放器

播放器基于网页原生视频能力建立自定义控制层。

显示控件：
- Play / Pause
- 极细 Progress 进度线，可拖动定位
- Volume / Mute
- Fullscreen

进入详情页后，首支视频以 `autoplay + muted + playsinline` 进入直接播放状态。
用户恢复声音后，后续视频继承当前音量状态。

交互：
- 鼠标移动 / hover 时控制层自然出现。
- 播放稳定后控制层淡出。
- 移动端通过触控显示控制层。
- 视频画面与页面背景形成一个整体视觉面。

## 10｜Poster

优先使用本地项目目录内明确指定的封面。
其余视频从 20% / 50% / 80% 时间点生成候选帧，选择主体清楚、画面完整、视觉质量最高的一帧作为 poster。

## 11｜验收

- 四项目列表截图：ivory / charcoal 两套主题均覆盖
- 四个项目的标题、主图、内部目录同步正确
- 选中标题动效与字体渲染清晰
- About 返回按钮在两套主题中清晰
- 每支视频标题、时长、画幅与实际 ffprobe 数据一致
- 当前视频拖动进度条定位准确
- 音量、播放、暂停、全屏工作正常
- Range 请求 206
- 当前视频与下一视频的 Network 加载顺序符合预加载方案
- Desktop / Mobile 播放截图
- Console error = 0
