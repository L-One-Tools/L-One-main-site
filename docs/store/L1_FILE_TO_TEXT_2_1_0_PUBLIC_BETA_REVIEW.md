## 渲染与交互决定

采用既有 CSS/DOM：内容需可选择、可读、可聚焦，且不需要 Canvas、SVG 或新图片。保留 hover、focus、离线 disabled、加载和 `prefers-reduced-motion` 的既有行为；不新增权限、账户、进度或下载完成逻辑。

缺失边界：没有新版界面截图、批量质量/速度测试结论、中文翻译稿/SRT/VTT 或自动歌词/台词裁决能力，页面不得补造。旧截图仅作位置示意；实际内测界面以安装后的资源中心为准。
