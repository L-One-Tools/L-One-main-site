## Rendering route（渲染路线）

- 采用 CSS/DOM + 原始图片：CSS Grid 和 `aspect-ratio` 固定右侧比例；图片仍以 `object-fit: cover` 适配；标题与链接保持为可选取、可聚焦的语义 DOM。
- 未采用 Canvas/WebGL：本轮没有需要实时生成的画面，且这些路线会降低标题链接和按键的可访问性。

## Interaction plan（交互计划）

- 已实现：标题下的原作链接、封面点击、`←` / `→`、ESC、滚轮、键盘切换。
- 状态：立体按键提供 hover、pressed、focus-visible 与 `prefers-reduced-motion` 的稳定回退；原作链接在新标签页打开。
