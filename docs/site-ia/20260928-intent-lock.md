# 主站入口与 About 视觉调整 Intent Lock

## 2026-09-28 第三轮覆盖决定：About 人物不得裁头

用户提供四张 1920×920 截图，明确要求每段人物头部和全部文字可见，并将“人物脑袋不得裁切”作为后续任务的硬约束。原视频是 1024×768（4:3）；先前为铺满宽屏使用 `cover` 与 SVG `slice`，导致人物头部越过顶部边界。下文第一轮“铺满”“统一裁切”决定已作废，不再作为验收依据。

当前候选让视频与 SVG 叠层共同保持完整 4:3 画幅，SVG 使用 `meet`，视频使用 `contain`；宽屏余下区域用页面底材承接。四个源视频时间点的原帧都包含完整头部。浏览器中已检查 1920 宽视口下视频框与画布边界：视频框居中且保持 4:3；逐帧动态浏览器截图仍需复核。验收时逐段检查头部、标题及说明文字，任一处裁切均拒绝发布。

模式：Adaptation。目标为 2026-09-28 主站本地候选；参考为 L-One 本轮两张桌面截图（Store 工具目录、About NOW）及现行页面。截图尺寸约 1829×885，页面缩放为用户所述默认 100%。当前没有头图运动视频、手机视口或作品集交互的同状态参考截图；相关画面对比只能作诊断。

| 字段 | 锁定意图 | 证据与可信度 | 实现约束 |
|---|---|---|---|
| 构图 | 一级入口覆盖六个栏目；作品集成为 Works 唯一一级目标 | 用户明确决定，高 | 保留已有作品集内容，不再并列展示旧 Works 归档 |
| 视觉焦点 | Store 和 NOW 中实际内容优先，图标退回合适比例 | 两张截图与用户反馈，高 | 缩小图标占比，保留真实原图 |
| 空间层级 | 主站顶栏贯穿 About、作品集、Library；主视觉仍可全屏显示 | 用户明确决定，高 | 顶栏与交互内容分层，避免覆盖点击目标 |
| 材质与光 | 保留白灰雾面 About 和暗色 3D Library，导航使用主站白底 | 现行页面，高 | 不重制图标、视频或 3D 卡片 |

路线：导航、图标尺寸与封面反馈由 DOM/CSS 处理；头图沿用现有视频及 SVG 叠层，以一致的裁切规则铺满桌面视口；现有作品集与 Library 的动画渲染方式保留。备选的全站重建会改变已确认的媒体与交互，不纳入本轮。

交互状态：导航 hover/focus/active 明确；工具只给已有公开详情页增加链接；作品封面 hover/focus 保持滚动循环同时有局部弹性；减少动态效果模式停止非必要滚动。无效/加载/错误状态沿用各页面现有逻辑。

优先级：P0 为六项入口可达、旧 Works 退出、已发布工具链接、About/作品集/Library 顶栏、头图无显著侧边空白；P1 为图标比例、滚动速度/间距、作品封面弹性；P2 为局部间距和阴影微调。用户审核前不标记最终视觉通过。
