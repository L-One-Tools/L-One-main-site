09 · FAQ

它会上传我的音视频吗

应用默认在本机处理媒体与输出，不向 L-One 服务上传媒体文件或转写文本。

模型已经放在安装包里吗

没有。模型由用户在资源中心主动下载。

为什么视频无法开始

检查 Windows PATH 中是否存在兼容 FFmpeg。WAV 音频不需要 FFmpeg。

我需要显卡吗

不需要。2.0.8 使用 CPU 运行，不含 NVIDIA GPU 运行时。

结果会百分百准确吗

没有百分百准确承诺。重要原稿需要自行核对。

卸载后文件会怎样

程序与快捷方式会移除；应用数据、模型目录与输出文件会保留。
