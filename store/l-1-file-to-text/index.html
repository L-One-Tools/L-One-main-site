L1

L-1 File To Text

把本地音频和视频转换成可保存、可阅读的 TXT、Markdown 或 HTML 文本。

2.0.8 公开可用

GitHub Release（正式发布页）提供 Windows 10/11 64 位安装包。下载前请核对 SHA-256（文件指纹）。

下载 Windows 安装包

适合谁

把本机音视频整理成可保存、可阅读的文字

适合整理采访、会议、课程、播客或视频素材的内容创作者与普通用户。不适合需要云端多人协作、不想使用本地模型，或希望当前版本直接使用 NVIDIA GPU 加速的用户。

功能与平台

范围以公开发布材料为准

输入
本地音频或视频文件；视频输入需要系统 PATH（程序查找路径）中可用的 FFmpeg。
输出
TXT、Markdown 或 HTML 文本。
平台
Windows 10/11 64 位（x64）。
版本
CPU 基础版，不包含 CUDA/cuDNN 或 NVIDIA GPU 运行时。

安装与首次使用

先核验，再安装

  1. 下载唯一的 2.0.8 Windows 安装包并核对下方文件指纹。
  2. 运行安装器；若 SmartScreen 显示“未知发布者”，先确认来源和指纹再决定是否继续。
  3. 首次启动选择模型目录，在资源中心主动下载 Whisper Small 或 Medium。
  4. 添加音频或视频，选择输出目录与格式后开始任务。

数据、隐私与权利

媒体与文本不上传到 L-One

用户媒体和转写文本不上传到 L-One 服务；任务记录、设置、缓存、模型和输出保存在本机。首次下载模型需要连接 Hugging Face。卸载不会自动删除模型、输出或本地设置目录。

软件权利声明、隐私说明、软件物料清单（SBOM）和第三方许可证均随 2.0.8 版本资料公开。

已知限制

CPU 基础版的明确边界

安装包不包含模型权重或 FFmpeg；模型需用户主动下载，视频输入需自行安装 FFmpeg。当前没有 NVIDIA GPU 加速运行时，也未做商业代码签名，Windows SmartScreen 可能提示“未知发布者”。2.0.7 仅保留为历史版本，不再推荐。

SHA-256

怎样核对文件指纹？

在安装包所在文件夹打开 PowerShell（Windows 命令行工具），运行：

Get-FileHash -Algorithm SHA256 -LiteralPath '.\L-1.File.To.Text.Setup.v2.0.8.exe'

输出的 64 位十六进制字符必须与本页文件指纹完全一致（字母大小写不影响比较）。不一致时不要安装，并重新从本页或正式 Release 下载。

FAQ

下载前可以确认什么？

现在可以下载或试用吗？

可以。请只从本页的 2.0.8 直接下载按钮或 GitHub Release 获取安装包，并在安装前核对文件指纹。

它会把我的文件上传到网络吗？

用户媒体和转写文本不上传到 L-One 服务。首次在资源中心下载模型需要连接 Hugging Face。

运行需要多少空间？

基础安装约 760 MB，建议至少预留 2 GB。Whisper Small 模型另需约 510 MB，Whisper Medium 另需约 1.53 GB。
