09 · FAQ

这是稳定版吗

不是。这是公开内测；大批量真实文件仍在测试，请先用小文件确认自己的流程。

安装包里已经有模型和 FFmpeg 吗

没有。首次打开后，在资源中心确认下载 FireRed 中文识别模型与 FFmpeg。

这次已验证到什么程度

已验证首次资源下载/校验和短样本本地 Markdown 转写，并通过 275 项自动测试；这不等于批量质量或速度验收。

能直接得到翻译稿、SRT 或 VTT 吗

不能。当前不提供中文翻译稿、SRT 或 VTT。

它会自动判断歌词或台词吗

不会。歌词或台词只作人工复核提示，不自动裁决。

我该去哪里反馈问题

在本页“反馈问题”入口提交，并说明 Windows 环境、使用步骤和可复现现象；不要上传私人媒体。
